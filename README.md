# 🎬 Netflix Clone - Login UI

A Netflix-inspired login page built with React and Bootstrap. Features a sleek dark theme with the iconic Netflix branding and bilingual (Marathi/English) interface.

## ✨ Features

- **Netflix-Styled Login** – Dark theme with Netflix red branding
- **Bilingual UI** – Marathi & English labels (साइन इन / Sign In)
- **Responsive Design** – Fully responsive with Bootstrap 5
- **React Router** – Client-side routing with React Router DOM v7
- **Clean Architecture** – Page-based component structure

## 🚀 Setup & Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/DeshmaneShubham/netflix-clone.git
   cd netflix-clone
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

   The app will open at `http://localhost:3000`
